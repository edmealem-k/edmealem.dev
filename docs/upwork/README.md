## Upwork TOS & Compliance Guidelines

To protect the Upwork account from flags or suspension, follow these guidelines:

1. **Pre-Contract Communications:**
   - **Never** share direct email, phone numbers, WhatsApp, Telegram, or personal calendars (Calendly) before a contract is started on Upwork.
   - Use Upwork's built-in Zoom/messaging for all pre-contract interviews.

2. **External Links in Proposals & Profile:**
   - Permitted: Upwork portfolio links, GitHub repositories (ensure repos do not prominently feature emails in the header), personal technical blog posts that do not have payment forms.
   - Prohibited: External links with "Book a call" buttons, contact forms, or payment processors (Stripe/PayPal/BuyMeACoffee).

3. **Writing Proposals:**
   - Focus on the client's problem in the first 2 lines (clients only see the snippet in the proposal list).
   - Reference concrete technologies: "I build production systems using Next.js 16, TypeScript, Hono, and PostgreSQL..."
   - Link directly to relevant portfolio pieces or GitHub codebases (e.g. `hono-commerce`, `DevVault`).
